# Дополнительные вопросы: статус решений

**Исходные вопросы остаются без замен и объединений.** Владелец проекта подтвердил, что кандидаты на новые вопросы подходят для дальнейшей работы. Формулировки описывают фактически совершаемое действие или проявившийся плод; ответы по шкале частоты показывают, как часто это происходит.

Актуальный список 14 кандидатов — в [единой редакторской таблице опросника](./Редакторская%20таблица%20опросника.md). ID 201–214 остаются черновыми, исходные 200 пунктов сохраняются без изменений. При добавлении кандидатов банк составит 214 вопросов.

Ранние предложения менять существующие вопросы отменены и не являются частью текущего плана. Опросник готовит данные для диаграммы Вороного; каждый самостоятельный вопрос может дать дополнительное наблюдение по назначенному качеству.
