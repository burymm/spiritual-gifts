# Кандидатные вопросы для подготовки к диаграмме Вороного

Статус: **рабочие кандидаты**. Решение владельца проекта: исходные 200 вопросов не заменять и не объединять. Эти дополнительные пункты можно включить после проверки формулировок; пока они остаются кандидатами и не меняют нумерацию исходного опросника.

Опросник — подготовительный способ получить значения качеств для последующего отображения на диаграмме Вороного. Каждый пункт описывает фактически совершаемое действие или проявившийся плод; респондент указывает частоту по принятой шкале. Скобки — скрытый аналитический тег.

Шкала ответов остаётся принятой: **Никогда / Иногда / Периодически / Часто / Всегда**.

## Финансовая дисциплина / Бережливость

## Учет в общей модели

- Проведена первичная смысловая сверка с исходными вопросами. Близкие темы есть у №201 и №204 с исходным №143 (личный бюджет и свободные средства); у №207, №209 и №210 — с №23 и №140 (доверие и конфиденциальность); у №212 и №213 — с №17, №43 и №61 (детали и проверка информации). Полных смысловых дублей не выявлено: кандидаты описывают более конкретные действия. Исходные и кандидатные вопросы остаются самостоятельными.
- №208 описывает ограничение раскрытия личных подробностей при привлечении помощи, №210 — хранение личных материалов, №211 — обращение за помощью при угрозе безопасности. Это разные действия, их не объединять.
- ID 201–214 — черновые ID дополнительных вопросов. Они не входят в исходную нумерацию 1–200, пока кандидатные формулировки не будут окончательно проверены.
- Если все 14 кандидатов добавить в банк, получится 214 пунктов. Это допустимо; для подсчёта качества число связанных вопросов само по себе не увеличивает его вес.
- Каждый вопрос влияет на назначенное ему качество. Ответы на дополнительные вопросы вместе с исходными ответами формируют данные для ДВ.
- Объединять вопросы и заменять ими исходные пункты не нужно. Разные формулировки могут давать дополнительные наблюдения для того же качества.
- Формулировки описывают действия в настоящем времени. Вопрос касается фактического поведения, а частота его проявления указывается выбранным вариантом ответа.
- Исходный `Терминология.docx` не изменён. Перед добавлением кандидатов нужно проверить, что их смысл не дублируется уже существующими вопросами, распределить итоговые ID и обновить карту качества.
