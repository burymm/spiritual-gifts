# Рабочая матрица 22 духовных даров

Статус: **согласовано как рабочая версия**. Коэффициенты и связи остаются гипотезами и не являются валидированной методикой.

Матрица предлагает сопоставить каждый дар с несколькими из 24 качеств. Коэффициенты внутри профиля суммируются до 1,0 и задают относительную важность качеств для сравнения с ДВ. Они не являются процентом вероятности дара и не доказывают его наличие. Это рабочая гипотеза для обсуждения и прототипирования.

## Принцип составления

- Сохранены пропорции существующих черновых профилей там, где они уже были заданы.
- Качества обозначены ID из [карты распределения вопросов](./Распределение%20вопросов%20по%20качествам.md).
- В старой матрице четыре дара были попарно объединены. В этой рабочей версии у каждого из 22 даров отдельный профиль.
- Для четырёх ранее объединённых даров приняты отдельные предложенные профили как гипотезы для дальнейшей проверки.
- Ни одна формула не означает, что качество само по себе является духовным даром. В частности, качества не измеряют непосредственно сверхъестественное действие Бога.

## Проверка арифметики

В каждом из 22 профилей сумма коэффициентов равна 1,0. Профили используют только ID качеств 1–24. Это проверка суммы и структуры, а не проверка богословской обоснованности или предсказательной силы.

## Следующие вопросы

1. Определить формулу сравнения профиля человека с профилем дара и корректное название процентного результата.
2. Решить, как показывать результат для Музыки и сверхъестественных даров, когда качества служат только косвенными признаками и не измеряют наличие дара напрямую.
3. Позднее проверить предложенные связи и коэффициенты на практике; согласование рабочей версии не означает эмпирическую или богословскую валидацию.
