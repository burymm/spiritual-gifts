# Черновые заметки: влияние и эмоциональная поддержка

Ранние варианты замены вопросов 52–54, 82–84 и 111–119 не применяются. По решению владельца проекта исходные вопросы сохраняются; объединять похожие пункты не нужно. Каждый вопрос остаётся дополнительным наблюдением для подготовки профиля качеств и диаграммы Вороного.

Дальнейшие дополнительные кандидатные вопросы должны описывать фактически совершаемые действия или проявившиеся плоды, а не намерение, старание или желаемую реакцию окружающих. Принятые ответы «Никогда / Иногда / Периодически / Часто / Всегда» уже позволяют оценить частоту фактического проявления.

Актуальные дополнительные кандидаты для слабых по покрытию качеств находятся в [единой редакторской таблице опросника](./Редакторская%20таблица%20опросника.md). Исходный `Терминология.docx` не изменён.
