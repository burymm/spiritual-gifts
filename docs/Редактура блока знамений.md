# Черновые заметки: вопросы о чудесах и языках

Ранние варианты замены вопросов 161–200 не применяются. По решению владельца проекта исходные вопросы остаются без замен и без объединений; вопросы о чудесах, знамениях, языках и истолковании продолжают влиять на назначенные качества.

Новые формулировки рассматриваются отдельно как дополнительные кандидаты, если они дают фактическое наблюдение для качества и помогают подготовить данные для диаграммы Вороного. Текущие кандидатные вопросы собраны в [единой редакторской таблице опросника](./Редакторская%20таблица%20опросника.md).

Исходный `Терминология.docx` не изменён. В будущих вопросах оценивается фактически совершённое действие или проявившийся плод; ответ отражает частоту этого факта по принятой шкале. Формулировки намерения или старания не используются.
