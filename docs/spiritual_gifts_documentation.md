## 📑 МОДУЛЬ 1: ВВЕДЕНИЕ И АРХИТЕКТУРНЫЕ ЦЕЛИ

### 1.1 Актуальность проекта
Настоящее веб-приложение разработано для решения критической проблемы современных евангельских общин, описанной в исследованиях д-ра Йоханнеса Раймера и Кристиана А. Шварца: менее 5% рядовых христиан знают свои духовные дарования, а более 80% не могут их определить, часто путая сверхъестественные харизмы с природной одаренностью (например, сводя все служение к утверждению «я умею хорошо петь»). 

Согласно библейскому основанию (Еф. 4:16, 1 Пет. 4:10), тело Христово получает приращение и созидает само себя в любви только тогда, когда каждый член действует в свою меру на своем месте. Субъективное восприятие христиан собственной жизни как счастливой напрямую зависит от того, служат ли они в соответствии со своими духовными дарами.

### 1.2 Целевая аудитория и роли пользователей
Приложение строго разграничивает интерфейсы под три целевые группы:
1. **Пастор (PASTOR) / Лидер малой группы (SMALL_GROUP_LEADER):** Получает «общую картинку» распределения Божьих ресурсов в общине, может собирать аналитические пулы по конкретным дарам для эффективного распределения обязанностей («собирать вещи руки, а ходить ногами»).
2. **Член церкви (CHURCH_MEMBER):** Проходит тестирование, калибрует результаты на интерактивной карте, видит свои сильные и слабые стороны, выстраивает траекторию личного служения.
3. **Приближающийся (SEEKER):** Помогает человеку понять, что у него есть важная миссия на земле, и мягко подводит к осознанному решению принять Христа (стать Его учеником) для её реализации.

### 1.3 Методология оценки 360 градусов
Для исключения субъективности, эгоистичных амбиций или ложной самооценки, итоговый профиль человека формируется на основании трех независимых анкет:
* *Личная анкета (SELF):* Самооценка человека на основе бытовых ситуаций.
* *Анкета близкого окружения (FRIEND):* Заполняется близким братом/сестрой во Христе.
* *Анкета пастора (PASTOR):* Оценка со стороны духовного руководителя общины.

## 🧮 МОДУЛЬ 2: МАТЕМАТИЧЕСКИЙ ДВИЖОК И МЕТРИКИ

### 2.1 Пятиступенчатая шкала ответов и расчётных баллов
Респондент выбирает частотный ответ. Для расчёта ответы кодируются значениями от 1 до 5:

| Вариант ответа | Балл для расчёта |
| :--- | :---: |
| **Никогда** | 1 |
| **Иногда** | 2 |
| **Периодически** | 3 |
| **Часто** | 4 |
| **Всегда** | 5 |

### 2.2 Алгоритм Этапа 1: Расчет стартового веса (Пул 480 единиц)
Каждый ответ добавляет 1 к привычной шкале 0–4. Благодаря этому индекс качества не бывает нулевым даже если на все его вопросы выбран ответ «Никогда». При равных индексах всех качеств стартовая диаграмма равномерна. Для 24 качеств общий пул составляет 480 единиц; в общем случае для N качеств он равен 20 × N.

#### Шаг 1. Расчет «Чистого индекса» качества
При полном заполнении анкеты для каждого из 24 качеств система считает среднее арифметическое баллов по привязанным к нему вопросам:
Индекс Качества = (Сумма баллов за ответы (1-5)) / (Количество вопросов, связанных с этим качеством)
*При полном заполнении анкеты индекс находится в диапазоне от 1.0 до 5.0.*

#### Шаг 2. Ограничения веса качества на диаграмме
При ручной калибровке вес одного качества — целое число: минимум 1, шаг 1, максимум N × 19 (для 24 качеств — 456). Общая сумма весов сохраняется: 480 при 24 качествах. Значение 0.05 из прежней версии ошибочно и больше не используется.

#### Шаг 3. Пропорциональное масштабирование в пул 480 единиц
Система распределяет общий пул пропорционально индексам всех качеств конкретного человека:
Стартовый вес качества = (Индекс Качества / Сумма индексов всех качеств) × (20 × N)
При 24 одинаковых индексах каждое качество получает 20 единиц. Дробные автоматические веса округляются методом наибольших остатков:
1. Для каждого качества взять целую часть пропорционального веса.
2. Вычислить, сколько единиц осталось до общего пула 20 × N.
3. Раздать оставшиеся единицы по одной качествам с наибольшими дробными остатками.
4. При равных дробных остатках использовать меньший ID качества первым.

Так сохраняется целая сумма 20 × N; приближённость округления приемлема для профиля. Ручная калибровка также использует целые единицы.

#### Заполнение анкеты и доступ к диаграмме
Анкета — необязательный путь подготовки профиля; основная цель — заполнить ДВ. Вопросы без ответа визуально отличаются от отвеченных. Индексы по ответам рассчитываются только при заполнении всей анкеты. Если пользователь пропускает вопросы или оставляет хотя бы один без ответа, частичные ответы игнорируются, а ДВ открывается с равномерным начальным профилем — по 20 единиц каждому из 24 качеств. Пользователь может откалибровать этот профиль и перейти к результату; пропуски не считаются ответом «Никогда».

### 2.3 Алгоритм Этапа 2: Калибровка на диаграмме Вороного
Получив N стартовых весов, приложение рендерит интерактивную карту (пример на Paper.js), где площадь ячейки прямо пропорциональна весу качества:
Доля площади качества = Вес качества / Общий пул
Доля площади в процентах = (Вес качества / Общий пул) × 100
Пользователь может менять веса на основе личного опыта, перераспределяя общий пул, который всегда равен 20 × N. Для 24 качеств это 480 единиц; согласованный диапазон ручного веса — от 1 до 456 с шагом 1. Сумма площадей всех ячеек составляет 100%. Геометрия (решение 26.10.2026): полигональная мозаика из клеток/шестиугольников, ориентир — пример Paper.js Voronoi; площадь клетки прямо пропорциональна весу. Небольшая геометрическая погрешность допустима: экран схематический, а точные вес и доля выводятся цифрами на клетке.

### 2.4 Алгоритм Этапа 3: выраженность дара по качествам (решение 06.11.2026)
Основной процент результата показывает, насколько сильно выражены качества, связанные с даром, а не близость к идеальному эталону:
1. Индекс качества — среднее ответов на его вопросы по шкале 1–5.
2. Вопросы 161–200 (исцеление, чудеса, языки, истолкование) **не участвуют в индексах качеств**: иначе отсутствие даров знамений занижает обычные качества. В анкете вопросы остаются и учитываются в проверке полноты.
3. Для даров 19–22 процент берётся **напрямую из блока**: 161–169 — Исцеление, 170–180 — Чудотворение, 181–190 — Разные языки, 191–200 — Истолкование. Это рабочая гипотеза по порядку блока, а не утверждённая методика.
4. Выраженность остальных даров (%) = (сумма коэффициентов дара × индексы их качеств) / (сумма коэффициентов) / 5 × 100.
5. 4 из 5 — это 80%, 3 из 5 — 60%, 5 из 5 — 100%.

Дары сортируются по выраженности; при равенстве — по меньшему ID. Топ-3 — первые три дара. Порог сильного выражения 75% и слабая зона ниже 50% применяются к этому проценту и проверяются на реальных результатах.

Для ручной калибровки и усреднённого профиля 360°, где ответов на анкету нет, индексы восстанавливаются из весов: вес 1 → 1, равномерный вес 50 → 3, максимальный вес → 5. Это вспомогательная шкала; для заполненной анкеты всегда используются реальные ответы. Прямого блока 161–200 в этом случае нет, поэтому дары 19–22 считаются по качествам.

Старое евклидово сравнение с идеальным профилем сохранено как справочный диагностический показатель (`match`), но не выводится как основной процент и не влияет на рейтинг: оно систематически завышает дары с большим числом коэффициентов (решение 06.11.2026). Проценты не являются статистически подтверждённой вероятностью.
