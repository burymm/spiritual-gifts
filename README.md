# Карта духовных даров

Веб-приложение для оценки духовных даров: инструкция → необязательная анкета
(214 утверждений) → калибровочная мозаика качеств → результат по 22 дарам.

Сейчас реализован **первый рабочий срез** — весь путь без авторизации, приглашений
и кабинета пастора. Данные не отправляются на сервер: профиль живёт в текущей
вкладке.

## Что уже работает

- **Инструкция** — объяснение шагов, шкалы и того, что проценты не являются
  вероятностью.
- **Анкета** — 200 основных + 14 кандидатских утверждений, шкала 1…5
  («Никогда» … «Всегда»), по 20 вопросов на страницу.
- **Диаграмма** — полигональная мозаика из шестиугольных клеток на пул из 480
  единиц: площадь области строго пропорциональна весу качества. Веса можно
  калибровать ползунками, сумма всегда остаётся 480.
- **Результат** — топ-3 дара и полный список 22 даров с процентами; сильная
  зона — от 75%, слабая — ниже 50%; отрицательные значения показываются как 0%.

Правила расчёта описаны в `docs/Контекст проекта.md` и
`docs/spiritual_gifts_documentation.md`. Markdown-файлы в `docs/` — источник
истины; при расхождении с DOCX/PDF побеждает Markdown.

## Структура

```
docs/                       требования и методика (Markdown — источник истины)
tools/generate-data.py      генерация TypeScript-данных из docs/
front/                      Angular 19 приложение
  src/app/core/             модели, конфиг, датасет, движок расчёта
  src/app/core/data/        сгенерированные вопросы, качества, дары, группы
  src/app/features/         instruction, survey, diagram, result
  src/app/state/            сигнальный store анкеты и весов
  tests/                    vitest-тесты движка, мозаики и store
```

## Запуск

Требуется Node.js 20+ и npm.

```bash
cd front
npm install
npm start          # http://localhost:4200
```

Маршруты: `/instruction`, `/survey`, `/diagram`, `/result`.

## Проверки

```bash
cd front
npm run test:engine   # vitest: движок, мозаика, store
npm run typecheck     # tsc для приложения и тестов
npm run build         # production-сборка
```

`npm test` (Karma + Jasmine) требует установленного браузера и оставлен для
компонентных тестов Angular; основные проверки идут через vitest.

## Данные

Вопросы, качества, профили даров и группы генерируются из Markdown-источников:

```bash
python tools/generate-data.py
```

Скрипт перезаписывает `front/src/app/core/data/*.data.ts` и
`_snapshot.json`. После правок в `docs/` запускайте его и проверяйте тесты.

## Настройки

`front/src/app/core/config.ts`:

- `INCLUDE_CANDIDATE_QUESTIONS` — включать ли вопросы 201–214 (по умолчанию
  `true`); выключение убирает их и из анкеты, и из ключа качеств;
- `STRONG_THRESHOLD = 75` — порог сильного выражения;
- `WEAK_THRESHOLD = 50` — порог слабой зоны;
- `TOP_N = 3` — сколько даров показывать в топе.

## Статус

Первый рабочий срез завершён: инструкция → анкета → мозаика → результат, всё
на типизированных данных из `docs/`. Код хранится в git (ветка `main`, первый
коммит — «Первый рабочий срез»).

Что осталось на следующие этапы:

- проверить порог 75% и матрицу 22 даров на реальных результатах;
- визуальная приёмка экрана диаграммы на реальных профилях;
- сохранение профиля (сейчас данные живут только во вкладке), авторизация,
  приглашения и кабинет пастора;
- общий результат 360° (усреднение профилей нескольких участников).

Матрица 22 даров и веса качеств — рабочая гипотеза, а не валидированная
методика.
